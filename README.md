# LeadGenBureau — AI Agency

Новый этап от 15.10.2026: полноценная главная агентства на `/agency/` и лендинг NeuroROP на `/neurorop/` по двум утверждённым директором референсам. Главная разделяет знакомство и продуктовую мозаику; NeuroROP показывает четыре связанных этапа и интерактивный разбор сделки. Старые концепты ниже сохранены. Новые страницы реализованы локально, без публикации и замены `/`.

Три самостоятельных интерактивных концепта LeadGenBureau на React + TypeScript + Vite: **C — AI Agency** по `/`, **A — Revenue OS** по `/revenue-os/`, **B — Sales Journey** по `/sales-journey/`. Общий переключатель позволяет сравнить их. Русские страницы, честные статусы продуктов, синтетические демонстрации и локальная подготовка описания задачи.

## Запуск

Проверено на Node.js 24.12.0. В PowerShell из корня проекта:

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173`).

```powershell
npm run check
npm run build
npm run preview
```

`check` проверяет оформление и линтинг через Biome. `build` включает строгую проверку типов и создаёт `dist/`. `format` применяет форматирование; `typecheck` отдельно проверяет TypeScript.

## Проверка поведения

При запущенном dev-сервере:

```powershell
npx playwright install chromium
npm run test:ui
```

Если Chromium уже установлен, скачивание можно пропустить и указать существующий исполняемый файл:

```powershell
$env:IMPECCABLE_BROWSER = 'C:\path\to\chrome.exe'
npm run test:ui
```

`PREVIEW_URL` позволяет проверить другой локальный адрес. Скрипты проверяют C/A/B на ширинах 320, 390, 1280, 1440 и 1536 px; A/B также на 1242 px, B на 768 px: выбор решений, клавиатуру, валидацию, экранирование текста и отсутствие отправки/хранения черновика. A проверяет стрелку и размеры текста. B проверяет четыре этапа, движение назад/вперёд, состояние при прокрутке и переходы между всеми концепциями. Снимки хранятся в `.impeccable/review/`. Пять HTML-входов позволяют открывать все маршруты на статическом хостинге без серверного роутера.

## Границы прототипа

Новые проверки `scripts/check-brand.mjs` включены в `test:ui`: обе страницы на 320, 390, 768, 1024, 1280, 1440 и 1536 px; переходы, якоря, меню и Escape, FAQ, демо и роли, валидация, экранирование, отсутствие отправки/хранения, reduced motion и перезагрузка. Снимки и измерения: `.impeccable/review/director-reference/`. В сборке теперь пять HTML-входов.

Лидогенерация — работающее направление; AI-звонилка — дорабатываемый MVP; NeuroROP — пилот; индивидуальные внедрения — развиваемое направление. Демонстрационные данные условные.

Формы ничего не отправляют и не сохраняют после перезагрузки. Backend, канал обращений и запись реального звонка не подключены. Новый лендинг NeuroROP доступен локально. Исторические концепты публиковались через Sites с публичным доступом; процедура — `docs/PUBLISHING.md`. Текущий этап не включает публикацию.

`PRODUCT.md` — факты и границы; `DESIGN.md` — новая дизайн-система; `docs/briefs/2026-10-15-approved-site.md` — утверждённый объём. `docs/CONCEPT_C_BRIEF.md` и `.impeccable/mocks/ai-agency.png` относятся к историческому C. Старые PRODUCT/DESIGN сохранены в `docs/archive/`. Локальный Impeccable находится в `.agents/skills/impeccable/`.
