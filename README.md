# LeadGenBureau — AI Agency

Два самостоятельных интерактивных концепта LeadGenBureau на React + TypeScript + Vite: **C — AI Agency** по `/` и **A — Revenue OS** по `/revenue-os/`. Русские страницы, честные статусы продуктов, синтетические демонстрации и локальная подготовка описания задачи. B — Sales Journey пока не реализован.

## Запуск

Проверено на Node.js 24.12.0. В PowerShell из корня проекта:

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173`).

```powershell
npm run check
npm run build
npm run preview
```

`check` проверяет оформление и линтинг через Biome. `build` включает строгую проверку типов и создаёт `dist/`. `format` применяет форматирование; `typecheck` отдельно проверяет TypeScript.

## Проверка поведения

При запущенном dev-сервере:

```powershell
npx playwright install chromium
npm run test:ui
```

Если Chromium уже установлен, скачивание можно пропустить и указать существующий исполняемый файл:

```powershell
$env:IMPECCABLE_BROWSER = 'C:\path\to\chrome.exe'
npm run test:ui
```

`PREVIEW_URL` позволяет проверить другой локальный адрес. Скрипты проверяют обе концепции на ширинах 320, 390, 1280, 1440 и 1536 px; A также на 1242 px: выбор решений, клавиатуру, валидацию, экранирование текста и отсутствие отправки/хранения черновика. A проверяет стрелку, минимальные размеры текста и мобильных ссылок. Снимки A сохраняются в `.impeccable/review/revenue-os/`. Два HTML-входа создаются при сборке, поэтому URL Revenue OS работает без серверного роутера.

## Границы прототипа

Лидогенерация — работающее направление; AI-звонилка — дорабатываемый MVP; NeuroROP — пилот; индивидуальные внедрения — развиваемое направление. Демонстрационные данные условные.

Формы ничего не отправляют и не сохраняют после перезагрузки. Backend, контакты, запись реального звонка и отдельные страницы продуктов не подключены. Концепты публикуются через Sites с публичным доступом; процедура — `docs/PUBLISHING.md`.

`PRODUCT.md` — факты и границы. `docs/CONCEPT_C_BRIEF.md` — выбранная композиция. `.impeccable/mocks/ai-agency.png` — утверждённый макет. Локальный Impeccable находится в `.agents/skills/impeccable/`.
