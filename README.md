# LeadGenBureau — AI Agency

Сайт AI-агентства LeadGenBureau на React + TypeScript + Vite с двумя страницами: главная `/agency/` и лендинг NeuroROP `/neurorop/`. Главная разделяет знакомство и продуктовую мозаику; NeuroROP показывает четыре связанных этапа и интерактивный разбор сделки. `/` — минимальная страница перехода на `/agency/`; неизвестные адреса показывают 404 со ссылкой на главную. Русский язык, честные статусы продуктов, синтетические демонстрации и локальная подготовка описания задачи.

## Запуск

Проверено на Node.js 24.12.0. В PowerShell из корня проекта:

```powershell
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173`).

```powershell
npm run check
npm run build
npm run preview
```

`check` проверяет оформление и линтинг через Biome. `build` включает строгую проверку типов и создаёт `dist/`. `format` применяет форматирование; `typecheck` отдельно проверяет TypeScript.

## Проверка поведения

Соберите проект (`npm run build`) и запустите сервер, затем:

```powershell
npx playwright install chromium
npm run test:ui
```

Если Chromium уже установлен, скачивание можно пропустить и указать существующий исполняемый файл:

```powershell
$env:IMPECCABLE_BROWSER = 'C:\path\to\chrome.exe'
npm run test:ui
```

`PREVIEW_URL` позволяет проверить другой локальный адрес. `scripts/check-brand.mjs` проверяет обе страницы на ширинах 320, 390, 768, 1024, 1280, 1440 и 1536 px: заголовки, якоря, меню и Escape, демонстрацию и роли NeuroROP, FAQ, валидацию и экранирование черновика, отсутствие отправки и хранения, перезагрузку и reduced motion. Дополнительно проверяются переход с корня на `/agency/` с сохранением query и hash, 404 на неизвестных и удалённых адресах и отсутствие прежних входов в `dist/`. Снимки хранятся в `.impeccable/review/director-reference/`.

## Границы прототипа

Лидогенерация — работающее направление; AI-звонилка — дорабатываемый MVP; NeuroROP — пилот; индивидуальные внедрения — развиваемое направление. Демонстрационные данные условные.

Формы ничего не отправляют и не сохраняют после перезагрузки. Backend, канал обращений и запись реального звонка не подключены.

`PRODUCT.md` — факты и границы; `DESIGN.md` — дизайн-система `/agency/` и `/neurorop/`; `docs/briefs/2026-10-15-approved-site.md` — утверждённый объём. Шрифт Montserrat размещён локально; лицензия: `src/assets/OFL-Montserrat.txt`.
