# OpenCode Agent Lab — 15 октября 2026

## Результат

Проектный Skill работает: Codex вызывает внешний OpenCode CLI, получает JSON-ответ,
проверяет результат и продолжает работу. По уточнению владельца агент работает
непосредственно во всём указанном проекте. Выбирать каждый файл или создавать
копию для обычной работы не нужно. Режим `edit` разрешает изменения и стандартные
проверки; анализ запрещает запись. Luna и настройки Codex/Cursor не менялись.

Установлен официальный `@opencode/cli` **2.0.29** глобально через npm.
Окружение: Windows, Node **24.12.0**, npm **11.18.0**, Python **3.14.2**.
`opencode --version`, `opencode run --help`, `opencode auth list` проверены.
Авторизаций нет; успешные тесты выполнены анонимно. Регистрация, карта, баланс,
подписки и API-ключи не потребовались. WSL, Docker и отдельные серверы не ставились;
`--standalone` использует временный приватный процесс сервера самого CLI.

Установка соответствует [документации V2](https://dev.opencode.ai/v2/docs/).

## Качество и проверка Sol

DeepSeek и Nemotron корректно изложили маршруты и тип `active`. Я сверил ответ
с исходником. У DeepSeek была неподтверждённая формулировка про «visually hidden/plain»
подпись без чтения CSS — её нельзя использовать как вывод о фактическом отображении.

MiMo правильно описал экспорты и зрелость продуктов, но смешал дефекты с будущими
рисками: привязку через индексы назвал потенциальным дефектом при отсутствии
текущей ошибки, а существование якорей оставил условным. Я проверил `AgencyApp.tsx`:
нужные `lead-generation`, `voice-agent`, `custom-agents` существуют. Эти замечания
не стали основанием менять сайт. Замечание о доступном имени требует проверки
в браузере; утверждение модели само по себе её не заменяет.

Исправление fixture у обеих моделей было точным и минимальным. Это маленькая
задача, а не доказательство качества на крупных изменениях. Дополнительная работа
Sol: прочитать diff, сверить факты с потребителями, повторить тесты; отдельного
хронометража этой проверки не было. Полноценного сравнения с Luna не проводилось.

Практическое применение: DeepSeek — ограниченный анализ модуля, простые изменения
и тесты; Luna — критичная логика и сложные подзадачи; Sol — архитектура, выбор
исполнителя и финальное решение. По этим единичным замерам DeepSeek был быстрее
MiMo, но вывод о стабильной скорости по такому объёму делать нельзя.

## Выявленные ограничения и исправления

1. На раннем вызове был HTTP 403 `FreeTierError` даже через официальный CLI.
   Ошибка похожего вида зарегистрирована в [официальном issue](https://github.com/anomalyco/opencode/issues/55443).
   Последующие вызовы работали без регистрации. Платный обход не использовался.
2. На холодном старте CLI выдавал два разных списка: встроенный без DeepSeek
   и свежий с DeepSeek. В исходнике есть загрузка bundled snapshot с последующим
   обновлением [каталога](https://github.com/anomalyco/opencode/blob/dev/packages/core/src/plugin/models-dev.ts).
   Обёртка передаёт неизменённый свежий каталог через штатный
   [OPENCODE_MODELS_PATH](https://github.com/anomalyco/models.dev#manual-testing-with-opencode),
   тот же JSON используется для проверки цены. После этого прямой и fix-вызовы
   DeepSeek прошли. Официальные ID и стоимость не подменяются.
3. Windows stdout Python использовал cp1251 и однажды не смог напечатать Unicode
   ответа, хотя файл отчёта уже был сохранён. Финальная обёртка печатает компактный
   ASCII-safe JSON; полный UTF-8 ответ хранится в `report.json`.
4. Тайм-аут убивает дерево конкретного CLI-процесса, возвращает частичные события
   и статус `timeout`, а не успешный результат.

## Стоимость и границы

Обёртка разрешает только перечисленные бесплатные ID, обновляет цены перед
вызовом и прекращает работу при неизвестной/ненулевой цене. Автоматического
перехода на платную модель нет. Используются новые анонимные XDG-каталоги,
унаследованные provider API keys в дочерний процесс не передаются. Модель
закреплена и для служебных агентов; warming/автосжатие отключены.

CLI сообщал стоимость `0` для доступных событий успешных тестов. Событие финального
шага V2 иногда не отдаёт, поэтому это сумма доступных метрик, а не сверка счёта
в платёжном кабинете. Платные модели и платные авторизации в тестах не применялись.

Используются реальные [V2 permissions/policies](https://dev.opencode.ai/v2/docs/permissions/),
а не только просьба модели. Чтение/поиск доступны по проекту; edit включает
редактирование и стандартные проверки npm/Node. Деплой, push, произвольные shell
команды и внешние каталоги не разрешены. Git/config/ключевые настройки исключены
из редактирования. Проверенные запреты — чтение внешнего синтетического файла и
отсутствие write/edit в analysis. Это не OS sandbox: доверенный CLI и доверенные
проектные test/build-скрипты выполняются с правами Windows-пользователя. Плагины,
symlink-атаки и все возможные способы выхода отдельно не аудировались.

## Использование и перенос

Skill: `.agents/skills/opencode-delegate/SKILL.md`.
Обёртка: `scripts/delegate.py`. Модели: `models.json`.
Offline-проверки: `scripts/test_delegate.py`.

Codex читает Skill и сам вызывает обёртку; пользователь задаёт обычную задачу.
Пример внутреннего вызова из корня репозитория:

```powershell
python .agents/skills/opencode-delegate/scripts/delegate.py `
  --root . --task .opencode-lab/task.txt `
  --mode edit --output .opencode-lab/run-unique
```

Для анализа убрать `--mode edit`. Для эксперимента с резервом добавить
`--model opencode/mimo-v2.6-flash-free`. Новый каталог результата обязателен,
чтобы не перезаписывать предыдущий запуск. Sol читает отчёт, проверяет diff
и тесты; внешняя модель не принимает финальное решение.

Перенос: скопировать всю папку Skill в `.agents/skills/` нужного репозитория,
проверить его локальные OpenCode-конфиги/плагины, затем открыть новый чат или явно
прочитать SKILL.md. Глобальная установка Skill, MCP и правки Luna не нужны.
В новом проекте локальные отчёты следует также игнорировать Git.

Локальная валидация: **7 offline-тестов обёртки**, **quick_validate: valid**,
**npm run typecheck**, **npm run check**, **git diff --check** — пройдены.
UI/build/deploy не запускались: приложение не менялось. Коммит и push не делались.
